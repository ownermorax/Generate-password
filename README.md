## About the Project

Generate-password is a desktop application for educational purposes, demonstrating the principles of generating cryptographically strong passwords and analyzing them using a modern password strength estimation library.

### Features

- Password generation with customizable length (from 8 to 32 characters)
- Selection of character types: digits, special characters, uppercase letters
- Automatic copying of generated password to clipboard
- Password strength analysis using the zxcvbn library
- Strength rating on a scale from 0 to 4
- Calculation of estimated time to crack the password
- Display of warnings and recommendations for improvement
- Simple and clean graphical interface using Tkinter
