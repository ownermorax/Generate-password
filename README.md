# Generate-password
Программа для генерации паролей и проверки их на стойкость.

![Python](https://img.shields.io/badge/Python-3.7+-blue.svg)
![Tkinter](https://img.shields.io/badge/Tkinter-Standard-green.svg)
![zxcvbn](https://img.shields.io/badge/zxcvbn-4.4.28+-orange.svg)

## О проекте
Generate-password - это десктопное приложение для образовательных целей, демонстрирующее принципы генерации криптостойких паролей и их анализа с использованием современной библиотеки оценки сложности паролей.

### Возможности
- Генерация паролей с настраиваемой длиной (от 8 до 32 символов)
- Выбор типов символов: цифры, спецсимволы, заглавные буквы
- Автоматическое копирование сгенерированного пароля в буфер обмена
- Анализ стойкости пароля с помощью библиотеки zxcvbn
- Оценка сложности по шкале от 0 до 4
- Расчёт примерного времени подбора пароля
- Вывод предупреждений и рекомендаций по улучшению
- Простой и понятный графический интерфейс на Tkinter
